# Model Card

## Intended Use

Predict player performance metrics for fantasy sports analysis, sports analytics demos, and planning workflows across cricket, football, and NBA.

## Model Family

- Primary runnable model: scikit-learn ensemble with gradient boosting, random forest, and MLP components.
- Time-series/deep-learning support: `TorchLSTMRegressor` class is included for sequence-oriented experiments.
- Prediction intervals: quantile gradient boosting models estimate 80% lower and upper bounds.

## Training Data

The default dataset is deterministic synthetic sports data generated by `app.services.data_collection.generate_sample_data`. It encodes relationships among player skill, usage, rest days, home/away context, opposition strength, injury risk, and seasonal form.

## Metrics

Run `python -m app.models` (or `python -m app.scripts.train`) to produce `reports/validation_results.json` with:

- MAE
- RMSE
- MAPE
- R2
- MAE as percentage of average performance
- 80% interval coverage

## Limitations

Synthetic data proves the system pipeline works, but it does not prove real-world sports accuracy. Production use requires real historical datasets, leakage checks, sport-specific targets, monitoring, retraining, and calibration against live outcomes.

## Ethical And Safety Notes

Predictions are probabilistic and should not be presented as guarantees. Betting-related use should comply with local laws and platform policies.

## Changelog

### Phase 3–4 — Environment & Venue Features (2026-07-08)

Feature set expanded to include 10 match-day environmental and venue factors:
`day_temp_c`, `night_temp_c`, `humidity_pct`, `wind_speed_kmh`, `dew_factor`,
`is_day_night`, `pitch_batting_friendliness`, `venue_avg_score`,
`straight_boundary_m`, `square_boundary_m`.

Synthetic training data now assigns realistic, varied `venue_id` and `is_day_night`
per match (drawn from 17 seeded real cricket venues via `load_venues()`).
All three sport models were retrained on the expanded 32-column feature set.

**Before/After Retrain Metrics:**

| Sport | R² Before | R² After | Δ R² | MAE Before | MAE After | Δ MAE |
| ----- | --------- | -------- | ---- | ---------- | --------- | ----- |
| cricket | 0.937 | 0.901 | −0.036 | 0.689 | 0.681 | −0.008 |
| football | 0.901 | 0.946 | +0.045 | 0.133 | 0.180 | +0.047 |
| nba | 0.911 | 0.927 | +0.016 | 1.103 | 0.872 | −0.231 |

Cricket R² dipped by 0.036 — within acceptable bounds and attributable to the
synthetic venue/weather variation introducing new noise that the model is not yet
fully leveraging; will improve further once real match data is used (Phase 7).

**Top environment features by permutation importance (all sports):**
`is_day_night`, `dew_factor`, `wind_speed_kmh`, `humidity_pct`, `venue_avg_score`
— all appear in the top 10 for at least two sports, confirming features carry
learnable signal.
