# Code Style Rules

## General Principles

- **PEP 8 Compliance**: Follow standard Python style guidelines.
- **Type Hints**: Use type hints for all function arguments and return types.
- **Docstrings**: Maintain docstrings for modules, classes, and public functions.
- **Clean Structure**: Group imports logically (stdlib first, third-party next, local modules last).
- **Absolute Imports**: Always use absolute imports starting with `app.`.
